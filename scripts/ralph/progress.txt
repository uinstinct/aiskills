## Codebase Patterns
- Registry layout: skills/<name>/{manifest.yml,SKILL.md}, agents.md/<name>/{manifest.yml,snippet.md}, src/external/ (Rust CLI), src/internal/ (Python maintainer scripts), .github/workflows/, root mapping.yml.
- mapping.yml is the single source of truth for the catalog (installed_skills, installed_agents_md). Every add/remove maintainer script must update it.
- Manifest yml fields used so far: name, description, version, harness_compatibility (array; empty = all), plus entrypoint (skills) or snippet_file (agents.md).
- Empty directories tracked with .gitkeep placeholders so layout survives git.
- Working branch: ralph/instinctagents (per PRD branchName). Create from main if missing.
- No pyyaml available in the default python3; lightweight scripts should use string parsing or vendor a tiny YAML reader rather than depending on pyyaml at lint time.
