## Codebase Patterns
- Registry repo layout: skills/<name>/, agents.md/<name>/, src/external/ (Rust CLI), src/internal/ (Python ingest scripts), docs/, scripts/, .github/workflows/.
- Top-level mapping.yml is the registry catalog; build script (US-005) will walk per-entry manifest.yml files to bake the offline catalog into the CLI binary.
- Two manifest variants share core fields (name, description, version, harness_compatibility) but each gets one optional type-specific field: skills -> entrypoint (default SKILL.md); agents.md -> snippet_file (default snippet.md).
- `name` in manifest.yml MUST equal the parent folder basename — this invariant is relied on by both the build script and the install/remove paths.
- Allowed harness_compatibility values are exactly: claude-code, codex, opencode. Empty list / omitted = compatible with all.
- prd.json is the source of truth for story state. After completing a story, flip `passes: true` and update `notes` with what was delivered.
- Branch: ralph/instinctagents (already checked out). Commit per story with `feat: [US-ID] - [Title]`.
- No Rust project bootstrapped yet (that's US-004), so "typecheck passes" for early documentation stories is satisfied trivially — no compile step exists to break.
