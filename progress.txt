- Files changed: `install.sh`
- **Learnings for future iterations:**
  - `case "${os}/${arch}"` pattern is clean for combined OS+arch dispatch in bash
  - Separate `local asset tag` declaration from assignment (e.g., `asset="$(check_platform)"`) avoids SC2155 shellcheck warning about masking return values

## Codebase Patterns
- Workspace Cargo.toml at root includes `src/external`; `cargo build` runs from root and outputs to `target/` at root level (not `src/external/target/`)
- Release workflow uses separate build jobs that upload artifacts, then a final `release` job downloads and publishes
